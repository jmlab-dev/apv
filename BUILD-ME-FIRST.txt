AMD Adrenalin Profile Viewer 1.1.13

LOCAL BUILD
===========
1. Install the .NET 8 SDK x64.
2. Run build-single-exe.bat.
3. The self-contained executable is created under:
   dist\AdrenalinProfileViewer-single-exe\AdrenalinProfileViewer.exe

GITHUB PUBLICATION
==================
1. Review LICENSE and NOTICE.md.
2. Run PUBLISH-TO-GITHUB.ps1.
3. Run CREATE-RELEASE.ps1.
4. GitHub Actions builds and publishes the versioned EXE and SHA-256 file.

See GITHUB-UPLOAD-CHECKLIST.md for full instructions.
